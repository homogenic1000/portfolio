index/Korg e-LIVEsEx jewel case

This is projet is an hommage for Nelson Weber, a great friend of mine and also a great compositor. It’s a cd book and jewel case i’ve designed, the track name is Korg e-LIVEsEx it’s mechanical, metallic, mysterious.

The inside of the cd book i’ve used the JetBrains Mono font face, it represent exactly the genre of the track ; nerdy, electronic, complex. It’s also a great open-source type that i personally love. The clustered line is a photo of the EMX-1 that i vectorized it’s a reference to how this track was made
